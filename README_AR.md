# Dafan Arena — مشروع لعبة Android

لعبة ساحات قتال ثلاثية الأبعاد خفيفة مبنية باستخدام Godot 4 وGDScript، مع واجهة لمس، حركة، إطلاق نار، صحة ونقاط، واستضافة/انضمام عبر ENet UDP.

## ما الذي يتضمنه المشروع؟
- ساحة ثلاثية الأبعاد مع حواجز وحدود.
- شخصية قابلة للحركة بواسطة WASD/الأسهم وعلى الهاتف عبر أزرار لمس.
- زر إطلاق نار مع احتساب إصابات ونقاط وصحة وإعادة ظهور.
- استضافة غرفة حتى 8 لاعبين، والاتصال بعنوان IP عبر UDP على المنفذ 24567.
- إعداد GitHub Actions لتصدير APK كـ Artifact.

## مهم بخصوص اللعب عبر الإنترنت
- اتصال `127.0.0.1` يصل إلى نفس الجهاز فقط، ولا يصلح للانضمام من هاتف آخر.
- للعب على نفس Wi-Fi استخدم عنوان LAN الخاص بهاتف/حاسوب المضيف وافتح UDP 24567 إن تطلب الأمر.
- للعب عبر الإنترنت من شبكات مختلفة تحتاج إلى خادم/عنوان عام قابل للوصول أو VPS، وفتح UDP 24567 في جدار الحماية. كثير من شبكات الهاتف تستخدم CGNAT وقد تمنع الاستضافة المباشرة؛ عندها استخدم VPS أو خدمة ترحيل مناسبة.
- هذه نسخة أولية قابلة للتطوير وليست لعبة تنافسية جاهزة للإنتاج. لا يوجد نظام حسابات أو matchmaking عالمي أو مكافحة غش متقدمة، ويجب اختبار سلوك الشبكة والأداء على أجهزة فعلية قبل النشر.

## بناء APK عبر GitHub من الهاتف
1. فك ضغط ZIP على هاتفك.
2. أنشئ مستودعًا جديدًا في https://github.com باسم `Dafan-Arena`.
3. ارفع محتويات المجلد مباشرة إلى جذر المستودع، بما فيها مجلد `.github` (تأكد أن خيار إظهار الملفات المخفية لا يخفيه عند الرفع).
4. افتح تبويب **Actions**. إذا طُلب منك تفعيل Actions فوافق.
5. اختر **Build Dafan Arena APK** ثم **Run workflow**. كما يبدأ البناء عند الدفع إلى فرع `main` أو `master`.
6. بعد انتهاء المهمة بنجاح، افتح المهمة وانزل إلى **Artifacts** ثم نزّل `Dafan-Arena-Android-APK`.
7. فك ضغط الـ Artifact وثبّت `DafanArena.apk` على جهاز Android. قد تحتاج إلى السماح بالتثبيت من هذا المصدر.

## البناء محليًا
ثبّت نسخة Godot 4.4.1 المطابقة وقوالب التصدير Android ثم افتح `project.godot`. اختر Project > Export > Android. إعداد التصدير في `export_presets.cfg` مخصص لبناء APK تجريبي ARM64.

## حدود النسخة الحالية
- لم يتم تنفيذ حسابات، دردشة، قائمة أصدقاء، matchmaking، متجر، أو خادم عام مستضاف.
- اتصال ENet مباشر، ويحتاج عنوانًا ومنفذًا قابلين للوصول.
- ملف APK لم يُبنَ أو يُختبر على جهاز حقيقي في بيئة الإنشاء هذه. GitHub Actions هو مسار البناء المقترح؛ إذا فشل، افتح سجل خطوة التصدير وشارك الخطأ.
